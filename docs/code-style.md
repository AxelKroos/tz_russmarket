# Стиль кода

Правила адаптированы из Atlas к React и Hono.

- Код на TypeScript. Компоненты сгруппированы по предметной области, общие
  элементы находятся в `app/components/common/`.
- Файлы компонентов используют kebab-case, имена компонентов — PascalCase.
  CSS-класс начинается с имени компонента, как в `.ScheduleGrid-cell`.
- Общие цвета, уровни наложения и длительности хранятся в
  `app/assets/styles/variables.less`. Адаптивные правила размещаются рядом
  со стилями компонента, начиная с мобильного размера.
- В Prettier используются четыре пробела, одинарные кавычки и ширина строки 100.
  Комментарии объясняют неочевидные правила и ограничения.
- Демонстрационные данные находятся в отдельном SQL-скрипте. В репозиторий
  попадают только параметры подключения к локальной демонстрационной базе.
- Перед передачей изменений проверяем форматирование, типы и сборку.
  Пользовательские сценарии проверяем в браузере.
- Сообщения коммитов следуют Conventional Commits.
