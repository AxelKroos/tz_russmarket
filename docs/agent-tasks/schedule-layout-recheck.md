# Повторная проверка вёрстки графика

- Дата: 17 ноября 2026 г.
- Среда: локальный редактор на `127.0.0.1:5173`, ветка `main`, Chrome.
- Функция: недельные карточки, панель выделения и оформление полей времени.
- Источник: [предыдущая сверка](schedule-layout-results.md) и
  [макеты Figma](https://www.figma.com/design/IOCJTroZMa4ioyNoYbk7c3/Untitled?node-id=403-2229).
- Агент: Codex.

Перед проверкой запустить локальный редактор. Подставлять график через
перехват ответа API во временном контексте браузера. Проверку сохранения и
публикации выполнять на отдельной базе Playwright. Данные рабочего сервера,
Figma и GitHub доступны только для чтения. Если локальная сборка или нужный
экран недоступны, остановить соответствующий пункт и отметить его как
`BLOCKED`.

| ------------------------------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 01. Интервал на мобильном             | PASS   | При 390 × 844 открыть записи `08:00–18:00` и `09:15–17:45`. Ожидаются компактная подпись целых часов и перенос полного времени внутри карточки. Получены `08 - 18` и две строки шириной 32,5 и 38,7 px в карточке шириной 68 px.                               |

| 03. Кнопка, своя смена и поля времени | PASS   | При 1700 × 1024 сравнить обычное состояние с макетом. Кнопка и своя смена стали светлее. Используется `#4f6fdc` с контрастом 4,53:1 для белого текста вместо цвета Figma `#5b7dec` с контрастом 3,76:1. Поля без фокуса и наведения показаны без значка часов. |

Форматирование, проверка типов и сборка прошли.                                                   |
