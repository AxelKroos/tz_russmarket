# Локальная проверка графика смен

- Дата: 17 ноября 2026 г.
- Среда: локально, Node.js 22.18.0, Chrome, PGlite и отдельный PostgreSQL 18.6.
- Функция: редактор смен, локальный черновик и опубликованный график.
- Источник: [ТЗ в Figma](https://www.figma.com/design/IOCJTroZMa4ioyNoYbk7c3/Untitled?node-id=403-2229) и [спецификация графика](../schedule.md).
- Агент: Codex.

Проверки меняли данные только во временных локальных базах и браузерных
контекстах. GitHub использовался для проверки имени авторизованного аккаунта.

| Check                             | Status | Comment                                                                                                                                             |
| --------------------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 01. Параллельная публикация       | PASS   | Два запроса с одной версией вернули 200 и 409. Чтение вернуло одну новую версию.                                                                    |
| 02. Валидация и откат             | PASS   | Запросы с невозможной датой, дубликатом и неизвестным сотрудником вернули 400. Версия и смены не изменились.                                        |
| 03. Продолжительность             | PASS   | Проверены вычисления 8 ч и 8 ч 30 мин, включая переход через полночь.                                                                               |
| 04. Работа с ячейками             | PASS   | В Chrome сработали диапазон, своя смена, редактирование, удаление, поиск, меню даты и перетаскивание. Покрытие обновлялось без перезагрузки.        |
| 05. Черновик и публикация         | PASS   | Черновик виден после перезагрузки в первом контексте. Второй контекст увидел смену после публикации. Локальный черновик удалён после ответа API.    |
| 06. Периоды                       | PASS   | Переход на соседнюю неделю и обратно работает. При ширине 390 px весь месяц доступен внутри таблицы с горизонтальной прокруткой.                    |
| 07. Сенсорное выделение           | PASS   | В сенсорном контексте Chrome двум выбранным касаниями ячейкам назначена одна своя смена.                                                            |
| 08. Хранение на диске             | PASS   | После закрытия и повторного открытия PGlite сохранились версия и состав опубликованного графика.                                                    |
| 09. Вёрстка, ресурсы и клавиатура | PASS   | Проверены 1700, 768 и 390 px. Меню ячейки открывается по Enter и возвращает фокус по Escape. Изображения загрузились, ошибок HTTP и консоли нет.    |
| 10. Отдельный PostgreSQL          | PASS   | API подключился к временному экземпляру PostgreSQL 18.6 по TCP. Проверены чтение, сохранение и отклонение параллельной записи с устаревшей версией. |
| 11. Сборка                        | PASS   | Прошли Prettier, проверка типов, сборка приложения и проверка конфигурации Docker Compose.                                                          |
