# Сверка вёрстки графика смен с Figma

- Дата: 17 ноября 2026 г.
- Среда: локальный редактор на `127.0.0.1:5173`, ветка `main`, Chrome, окна 1700 × 1024 и 390 × 844.
- Функция: календарь, панель шаблонов, выделение и карточки смен.
- Источник: [фреймы редактора в Figma](https://www.figma.com/design/IOCJTroZMa4ioyNoYbk7c3/Untitled?node-id=403-2229).
- Агент: Codex.

Для сравнения график подставлялся в отдельном браузерном контексте.
Сверка не меняла исходный код, Figma, GitHub или данные сервера.
Пустой фрейм получен заново. Для остальных состояний использованы рендеры
и размеры, полученные при первом чтении макета, поскольку Figma MCP достиг
лимита повторных запросов.

## Заблокированные проверки

- **07: BLOCKED** — точную сверку мобильной компоновки с Figma выполнить
  нельзя. В предоставленной группе фреймов все экраны имеют размер
  1700 × 1024. Адаптивная версия проверена в Chrome при 390 px.

Даты, суммы часов и количество назначений в редакторе вычисляются из
данных. В макете они местами заданы вручную и расходятся с интервалами,
поэтому сами числа не служили критерием визуального совпадения.
